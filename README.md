# Jinay Gadiya - Personal Portfolio Website

A modern, elegant, and fully responsive personal portfolio website showcasing Jinay Gadiya's journey as an aspiring entrepreneur and boxing athlete.

## 🌟 Features

### Design & Aesthetics
- **Modern Dark Theme** - Elegant black background with gold accents inspired by luxury e-commerce sites
- **Sophisticated Typography** - Combination of Playfair Display (headings) and Inter (body text)
- **Smooth Animations** - Fade-ins, slide-ups, parallax effects, and interactive hover states
- **Fully Responsive** - Optimized for all devices (mobile, tablet, desktop)
- **Accessibility** - Semantic HTML, keyboard navigation, and ARIA labels

### Sections

#### 1. Hero Section
- Animated welcome badge with status indicator
- Large, eye-catching typography with gradient text effects
- Professional profile image with floating animation
- Dual call-to-action buttons
- Animated statistics counter
- Smooth scroll indicator

#### 2. About Section
- Two-column layout with decorative elements
- Inspirational quote display
- Three highlight cards showcasing key attributes
- Smooth reveal animations

#### 3. Education Section
- Interactive timeline design
- Animated timeline markers with pulse effects
- Detailed education cards with hover effects
- Subject tags for quick reference
- Current/Completed status badges

#### 4. Passions Section
- Two featured passion cards (Entrepreneurship & Boxing)
- Custom SVG icons
- Feature lists with checkmarks
- 3D tilt effect on hover
- Gradient backgrounds

#### 5. Journey Section
- Four-step journey visualization
- Numbered cards with elegant styling
- Progress indicators
- Hover effects with top border animation

#### 6. Contact Section
- Three information cards (Location, Email, Social)
- Fully functional contact form with validation
- Real-time form submission with loading states
- Success/Error notification system
- Beautiful gradient background

#### 7. Footer
- Multi-column layout with quick links
- Social media integration
- Copyright and credits
- Consistent branding

### Interactive Features

#### JavaScript Enhancements
- **Preloader** - Smooth loading animation on page load
- **Sticky Navigation** - Transparent navbar that becomes solid on scroll
- **Mobile Menu** - Hamburger menu with smooth transitions
- **Active Link Highlighting** - Navigation links highlight based on scroll position
- **Counter Animation** - Stats animate when scrolled into view
- **Scroll Reveal** - Sections fade in as you scroll
- **Parallax Effects** - Hero section moves at different speeds
- **Back to Top Button** - Appears after scrolling down
- **Form Validation** - Client-side validation with helpful error messages
- **Notification System** - Toast notifications for form submissions
- **Keyboard Navigation** - ESC to close menus, Home to scroll to top
- **Lazy Loading** - Images load only when needed
- **Performance Optimizations** - Debounced scroll events

### Technical Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** - No dependencies, pure ES6+
- **Google Fonts** - Playfair Display & Inter

## 🔧 Customization

### Changing Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-gold: #d4af37;
    --primary-black: #0a0a0a;
    /* ... more variables */
}
```

### Adding/Removing Sections

1. Add/remove HTML section in `index.html`
2. Add corresponding navigation link
3. Style in `styles.css`
4. Add scroll reveal animation in `script.js`

### Modifying Content

All content is in `index.html`. Simply edit the text within the HTML tags.

### Form Integration

To connect the contact form to a backend:

1. Add `action` attribute to form in HTML:
   ```html
   <form id="contactForm" action="YOUR_FORM_ENDPOINT">
   ```

2. Popular form services:
   - [Formspree](https://formspree.io/)
   - [Netlify Forms](https://www.netlify.com/products/forms/)
   - [Web3Forms](https://web3forms.com/)
