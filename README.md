# Jinay Gadiya - Portfolio Website

A modern, responsive portfolio website for Jinay Gadiya, a business student and aspiring entrepreneur from Pune, Maharashtra.

## About

This website showcases Jinay's educational background, entrepreneurial aspirations, and passion for boxing. Built with a clean, modern design featuring smooth animations and responsive layouts.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Dark theme with neon yellow accents
- **Smooth Animations**: Scroll-triggered animations and smooth transitions
- **Contact Form**: Integrated contact form for easy communication
- **Mobile Menu**: Hamburger menu for mobile navigation

## Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive functionality and animations

## Sections

1. **Hero Section**: Bold introduction with name and tagline
2. **About**: Personal description and background
3. **Education**: Academic qualifications and current studies
4. **Passions**: Entrepreneurship and boxing interests
5. **Contact**: Contact form and LinkedIn connection

## Customization

To customize the website:

1. **Colors**: Edit the CSS variables in `styles.css` under `:root`
2. **Content**: Modify text directly in `index.html`
3. **Profile Image**: Replace the placeholder in `.profile-image` section
4. **Contact Form**: Connect the form to your preferred backend service

## How to Use

1. Open `index.html` in any modern web browser
2. To deploy: Upload all files to your web hosting service
3. For local development: Simply open the HTML file or use a local server
